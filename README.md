# FitCore — iOS Fitness & Nutrition Tracker

Personal iOS app for health tracking, personalized calorie targets, and activity monitoring — built from scratch in Swift.

## Stack

| Area | Technology |
|------|------------|
| Language | Swift |
| Backend | Firebase (Auth, realtime sync, cloud storage) |
| Nutrition APIs | USDA FoodData Central, Food101 |
| Charts | Swift Charts |
| Platform | iOS (Human Interface Guidelines) |

## Features

- **Nutrition tracking** — macros (calories, protein, carbs, fats) from integrated food databases
- **Dynamic calorie monitoring** — daily intake/expenditure charts with automatic midnight reset
- **Activity** — step tracking and estimated calorie burn
- **Fitness diary** — log workouts, set goals, review progress over time
- **Personalized targets** — Harris–Benedict–based calorie recommendations
- **Auth & sync** — Firebase authentication with encrypted cloud storage

## Why it matters

End-to-end mobile product work: native UI, third-party APIs, secure auth, and live data visualization — not just a UI mock.
